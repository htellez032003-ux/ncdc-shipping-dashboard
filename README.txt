NCDC Shipping Dashboard (Offline Phase 1)
------------------------------------------------
This version runs entirely offline for testing & demonstration.

How to upload to GitHub Pages:
1. Go to your repo: https://github.com/htellez032003-ux/ncdc-shipping-dashboard
2. Click 'Add file' → 'Upload files'.
3. Upload all extracted files from this folder.
4. Commit changes.
5. Visit: https://htellez032003-ux.github.io/ncdc-shipping-dashboard/

Features:
- Login simulation (admin auto-login)
- Light theme dashboard
- Mock data from sample-data.js
- Works 100% offline
